# Advanced-Chat-BombSquad

Advanced Chat Version Dark - The complete, unified chat suite and overhaul mod for BombSquad.

## Features
- **Real-Time Translation**: Multi-engine (Google & MyMemory) translation. Single click translates incoming messages; 'Trans' button translates typed text.
- **Server Chat History**: Pure Python zero-dependency persistent storage with full session timelines, player rosters, and global text search.
- **PBID & Account Lookup**: Inspect any player's PBID, account age, creation date, ranks, trophies, achievements, and linked accounts (V2, Android, Apple, Steam) with one-click live server player scanning.
- **Remote Auto-Updater**: Asynchronous background update checking and safe in-place patching with syntax verification.
- **Discord Error Telemetry**: Isolated error tracking dispatching to a secure webhook with player and platform diagnostics.

## Supported Versions
- **API 8**: `Advanced_chat_version_dark_api8.py` (BombSquad 1.7.20 - 1.7.36)
- **API 9**: `Advanced_chat_version_dark_api9.py` (BombSquad 1.7.37 - 1.8.7+)
